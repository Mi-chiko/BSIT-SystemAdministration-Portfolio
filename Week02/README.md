# Week 02 – Enterprise Infrastructure Planning
Project Overview

This project is an IT Infrastructure plan for ABC Startup Solutions, a fictional software development company with 20 employees. It covers hardware, software, networking, system management roles, security, backup, and future growth.

Learning Objectives
Plan IT infrastructure based on business requirements.
Prepare hardware, software, and network inventories.
Design an enterprise network topology.
Document IT infrastructure professionally.


Company Scenario
ABC Startup Solutions is a software development company located in Santa Rosa City, Laguna. It has 20 employees distributed among IT, HR, Finance, and Sales departments.


Hardware Inventory Summary
The proposed infrastructure includes desktop computers, laptops, a server, monitors, networking equipment, printers, UPS units, wireless access points, NAS storage, and backup drives.

Software Inventory Summary
The organization will employ Windows 11 Pro, Ubuntu Server, Microsoft 365, Visual Studio Code, Git, GitHub Desktop, VirtualBox, Google Chrome, Microsoft Defender, Any Desk and 7-Zip.

Reflection
This project taught me that planning is important before establishing IT infrastructures. It enhanced my skills in infrastructure planning, documentation, networking and system administration.
